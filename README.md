# Veda Technology – Task 7: Basic Calculator

## 📌 Project Overview

The Basic Calculator is a front-end web development project created as part of Task 7 of my Web Development Internship at Veda Technology.

This project performs basic arithmetic operations using an interactive calculator interface built with HTML, CSS, and JavaScript.

## ✨ Features

- Addition, subtraction, multiplication, and division
- Decimal number support
- Interactive calculator buttons
- Clear (AC) functionality
- Delete (DEL) functionality
- Equals button to display calculation results
- Division-by-zero error handling
- Responsive design for desktop and mobile devices
- Clean and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Button events and arithmetic calculations

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/mullapatinagalaxmi-2005/veda-task-7-basic-calculator.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.
